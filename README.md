# Team Task Manager

A full-stack Team Task Management web application built using React, Node.js, Express, and MongoDB.

## Features

- User Signup/Login Authentication
- JWT Authentication
- Project Management
- Task Assignment
- Task Status Tracking
- Dashboard with Task Statistics
- MongoDB Database Integration
- RESTful APIs

## Tech Stack

### Frontend
- React
- Axios
- React Router DOM
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- bcryptjs
